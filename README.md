# PS1 dragon snow globe

A low-poly orange dragon on a snowy island, rendered the way a PlayStation 1
would: 240-line output, vertex wobble, affine texture warp, per-vertex
lighting, 15-bit dither. Drag to orbit, tap to shake.

Live: https://nicksramcik.github.io/ps1-dragon-globe/

Built with Blender (scripted) and three.js r170 (MIT, `vendor/THREE-LICENSE`).
